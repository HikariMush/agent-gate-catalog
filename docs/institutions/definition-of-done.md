# 完了の定義

**1行**: 「完了」と報告してよいのは**検証コマンドとその実出力が貼ってある**ときだけ。文章だけの完了報告は未完了として扱う。派生則として **設置の実出力 ≠ 成功の実出力**。

## 世界標準の名前

Definition of Done（Scrum）＋ audit evidence（統制は方針でなく運用証跡で証明する）。派生則は deadman's switch / synthetic monitoring と同型。

## 発火（何がこれを動かすか）

全レーンに常時適用（運用規範の本文に焼いてある）。

## 実測 / 観測

定期実行を作ったら**次の発火を待って成功の痕跡**を確認する。待てないなら「未検証（次回発火で確認）」と明記する。成功時に無出力のジョブは、失敗時の無言と区別がつかない。

## 注記

世界でも「DoD はあるが誰も検証しない」が指摘されている。ここでの差分は**証拠の貼付を報告書式で強制する**点。
