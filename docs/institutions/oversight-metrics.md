# 監督の質の実測

**1行**: 人の監督が名前だけになっていないかを週次で測る。止まる質問の応答時間、拒否猶予の不行使率、掲示の未読日数、相互監査の率、外向き・不可逆・課金の件数。

## 世界標準の名前

Rubber-stamp rate / override rate / HITL necessity rate。承認率が高止まりする human-in-the-loop は名前だけの human-in-the-loop、という観測が根拠。

## 発火（何がこれを動かすか）

週次の定期実行。形骸化のシグナルが**2週連続**で立ったときだけ人に1件掲示する。

## 実測 / 観測

初回実測: 拒否猶予の不行使 11/16（68.8%）・覆した記録 0/11・掲示の最古の未読 20.2日。**履歴が1週分しかないので、シグナルは構造上まだ発火しない**。

## 注記

**この指標の分母に注意**。世界の override rate の分母は「人がレビューした提案の数」で、ここでの 0/11 の分母は「レビューされずに期限で自動確定した件数」にあたる。
