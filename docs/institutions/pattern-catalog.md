# 定石台帳

**1行**: 「症状 → 確立された解法 → 処方 → 現在地（導入済 / 部分 / 未）」の台帳。同種の問題が2回目・事故対応・同じ手作業の繰り返し・新しい仕組みの設計前、のいずれかを見たら**頼まれなくても**台帳を症状で引いて提言する。

## 世界標準の名前

Pattern language / pattern catalog（Alexander: 問題と解の核を対にして繰り返し使う）＋ SRE の runbook（症状 → 検証済みの是正手順 → 確認）。

## 発火（何がこれを動かすか）

セッション開始時の手順（弱い結線）。

## 実測 / 観測

台帳の各行が既に世界標準の名前（SRE・ソフトウェア工学・セキュリティの定石名）で書かれている。

## 注記

台帳に無い解法で問題を解いたら、台帳を更新してから完了とする。
