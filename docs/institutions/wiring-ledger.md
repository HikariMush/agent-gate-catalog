# 結線台帳

**1行**: どの制度が何によって発火するか（定期実行 / hook / ワーカーが読むファイル / セッション開始時の手順 / 未結線）を1ファイルに集約した正本。制度を新設・改訂したら台帳に1行足すまでを完了とする。

## 世界標準の名前

Control inventory / control registry ／ CMDB の「権威ある構成記録」。

## 発火（何がこれを動かすか）

台帳そのものは文書。突合は下記 `wiring-check` が日次で行う。

## 実測 / 観測

台帳が手書きで現物とズレていた実測が5件あり、いずれも記述側を現物に合わせて訂正した。

## 注記

**発火経路が書けない制度は未結線＝存在しない扱い**にする、が運用上の要点。
