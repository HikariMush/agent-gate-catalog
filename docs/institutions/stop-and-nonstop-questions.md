# 止まる質問と止まらない質問

**1行**: 人への問いを2種類に機械分類する。不可逆・外向き・お金に触れるものは「止まる質問」で、明示回答が無い限り進まない。それ以外は「止まらない質問」で、期限が来たらデフォルト案で自動確定して進む。**可逆性で期限の意味が反転する**。

## 世界標準の名前

止まらない側 = lazy consensus（沈黙は同意・ASF）／法制度の同型 = default enactment・pocket veto。止まる側 = HITL approval gate / irreversibility-based gating。全体は fail-closed（判定不能は止める側に倒す）。

## 発火（何がこれを動かすか）

分類は宣言したアクションを内蔵の動詞表と外部経路の台帳に突き合わせて機械導出する。期限処理は1日2回の定期実行。

## 実測 / 観測

拒否猶予が与えられた16件のうち11件が期限で自動確定（68.8%）、期限後に覆した記録は0/11。

## 注記

世界の autonomy gating は「行為」を分類するが、ここでは**人への問い**を分類する。目的は人の注意の節約にある。
