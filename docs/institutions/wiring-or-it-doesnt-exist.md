# 結線されていない制度は存在しない

**1行**: ルール・ゲート・チェックリストを作ったら「何が・いつ・どうやって発火させるか」を実装するまで完了としない。人の「思い出したら実行する」に依存する制度の新設を禁止する。

## 世界標準の名前

Policy as code / compliance as code。裏返しの失敗名は paper compliance・shelfware（書いただけで誰も実行・検査しない統制）。

## 発火（何がこれを動かすか）

この規範自体はセッション開始時の手順（弱い結線）。個々の制度は下記の台帳で発火経路を持つ。

## 実測 / 観測

台帳に「未結線」と記録された制度が現に残っている（下の `wiring-ledger` 参照）。全部が結線済みの状態を配ってはいない。

## 注記

世界の policy-as-code は主に CI/CD とクラウド構成が対象。ここでは**散文の運用規範**に適用している点が拡張になる。
