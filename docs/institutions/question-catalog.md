# 問いの正本（問いカタログ）

**1行**: 事業や運用が詰まったときに通す問いの一覧。答えは書かず、問いと「浅い答えの実例」と出典だけを書く。答えは腐るが問いは腐りにくい。

## 世界標準の名前

**(b) 新レール候補**。最近縁 = structured analytic techniques（Heuer/Pherson。key assumptions check 等の問いの型の手続き化）／ Socratic questioning ／ checklist ／ 回答の接地強制は grounded generation・policy-enforced generation。

## この型が普通の質問リストと違う2点

1. **問いの掲載資格**: 問いを追加するには、**その問いが過去に実際に判断を変えた実績（出典）**が要る。出典のない問いを載せてはいけない
2. **回答の機械ゲート**: 回答は会話に流さずファイルに書き、決定論スクリプトが形式と接地（引用・数字・パスの有無、禁止語彙）を検査する。通らない限り**未回答**として扱う

policy-enforced generation は**生成の出口に置く出力フィルタ**で、規則違反の出力を拒否する。この型は ①問い（計器）の側に掲載資格を課す ②拒否の基準が規則違反ではなく**一次資料を開かずに書いた浅さ**である、の2点で外れる。

## 発火（何がこれを動かすか）

月次の経営判断の冒頭 / タスク起案の前 / 人への裁定依頼を組む前、の3つを強制発火点にする。「詰まったら読む」は禁止（詰まっているときは詰まりを自覚しないため）。

## 実測 / 観測

問いの効き目ログに、その問いが変えた裁定のIDを1行で残す。**IDなしの「効いた」は無効**とする。

## 回答の書式

1問 = **事実 / 判定 / 一手**の3欄。事実欄には、開いた実物からの引用・数字・パスを最低1つ。無ければ「計測なし（探した場所: …）」と書く（**探さずに無いと言うのを禁止する**）。

## 注記

裁定に使う回答の出典照合は、**回答を書いたのとは別の経路**で行う（自己検収の禁止の問い版）。照合は判断ではなく突合なので、担当の質に左右されにくい。
