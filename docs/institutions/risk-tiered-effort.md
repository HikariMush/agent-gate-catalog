# 推論予算のリスク階層配分

**1行**: 作業のリスク階層に応じて思考予算を変える。決定論チェックで合否を担保できる機械的作業は低予算、不可逆・外向き・お金の判定だけ最大にする。

## 世界標準の名前

Risk-based testing の graduated allocation（高リスクは全テスト / 中は部分集合 / 低はスモークのみ）を、テスト工数ではなく推論予算に当てたもの。近縁に model cascade（FrugalGPT）。

## 発火（何がこれを動かすか）

各ゲートの実行時。

## 実測 / 観測

機械的作業を低予算に落とせるのは、その合否を決定論チェックが担保しているから。決定論で担保していない判定を低予算に落とすのは手抜きになる。

## 注記

難問でも頭打ちを超えて積まない（過剰な思考は費用と遅延だけ増やし、易問では正答を捨てることすらある）。
