# 制度文書と現物の自動突合

**1行**: 散文で書かれた運用規範から**機械で検査できる主張だけ**を抽出し、定期実行の設定・hook・ファイルの実在と突き合わせる決定論チェッカー（判定に言語モデルを使わない・読み取りのみ）。

## 世界標準の名前

**(b) 新レール候補**。最近縁 = configuration drift detection / desired-state reconciliation（ただし宣言側が構造化定義である前提）、doctest・executable documentation（文書に実行可能例が埋まっている前提）、ARPaCCino（自然文ポリシー→Rego→IaC）、PROPARAG（自然文の方針書を統制標準に照らす。突合の相手も文書）。

## 発火（何がこれを動かすか）

日次の定期実行。

## 実測 / 観測

抽出できた主張だけが検査対象になるので、検査できなかった件数も出力に含める（隠さない）。

## 注記

散文抽出の側と実ホスト走査の側（OpenSCAP / CIS Benchmark。入力は機械可読プロファイル）は別々に成熟しており、交差した運用単位は検索で見つからなかった。
