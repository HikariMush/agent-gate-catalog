# 公開物のレジストリと出口検査

**1行**: 公開面を定期的に走査し、守秘語・開示の上限・断定を検査する。**置き場所ではなくファイル単位のレジストリ**で公開物を判定する（「この文書を読む生成器があるか」で登録する）。検知の詳細は人に出さず、面と件数だけを通知する。

## 世界標準の名前

DLP（NIST CSRC の定義: A system's ability to identify, monitor, and protect data in use）＋ data classification ＋ content inventory。

## 発火（何がこれを動かすか）

10分ごとの定期実行（公開ジョブの直後に走らせる）。

## 実測 / 観測

台帳と検査面の機械突合で登録漏れ0件、既存在庫の棚卸しも全面で件数一致を実測。

## 注記

**公開と内部を置き場所で判定している限り、内部に置いてある公開物は漏れ続ける**。**ゲートは未来にしか効かない。過去は棚卸しでしか消えない**。
