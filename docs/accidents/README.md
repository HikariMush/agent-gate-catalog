## 共通して効いた一般則

- **設置の実出力 ≠ 成功の実出力**。「登録した」ではなく「次の発火が成功した」まで見る
- **うるさい欠陥を消すときは、そのノイズが何かを補償していないかを先に問う**（リトライ・重複・揺れは別の欠陥の症状緩和になっていることがある）
- **公開と内部を置き場所で判定している限り、内部に置いてある公開物は漏れ続ける**
- **ゲートは未来にしか効かない。過去は棚卸しでしか消えない**
- **注入と遵守は別物**。発火ログは「届いたか」の証拠であって「従ったか」の証拠ではない
- **0件は「無い」ではなく「その式では当たらなかった」**。検索式の生存を、必ず当たるはずの語で確認する
