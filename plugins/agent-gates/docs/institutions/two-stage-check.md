# 二段ゲート

**1行**: 公開・課金・go 判定に載る成果物は、実装者と別セッション・**安い別モデル**の検査役に「成果物と合格基準だけ」を渡して独立判定させ、合格のときだけ人間ゲートへ上げる。実装側は**安いモデルが独立に正誤判定できる粒度**で書く義務を負う。

## 世界標準の名前

Prover-Verifier Games（arXiv:2407.13692・強い prover の出力を小さい verifier が検査できる粒度に保つ）＋ LLM-as-a-judge ＋ four-eyes の機械版。

## 発火（何がこれを動かすか）

節目（公開・課金・裁定の前）。

## 実測 / 観測

検査役には意図・経緯・結論を渡さない（渡した瞬間に同じ穴に落ちる）。

## 注記

限界: 判定を言語モデルに委ねる部分は reward hacking と Goodhart に脆い。**機械で担保できる所を先に決定論チェックへ置く**のが前提。
