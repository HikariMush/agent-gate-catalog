# 注入と発火証明と遵守観測は別物

**1行**: 制度を毎メッセージ注入する結線を作ったら、①注入したか ②発火したか ③**実際に守られたか**、を別々に観測する。遵守観測のない制度を「稼働中」と呼ばない。

## 世界標準の名前

Instruction-following compliance rate（IFEval 系ベンチの運用版）＋ 「system prompt は instruction であって control ではない」という統制論。

## 発火（何がこれを動かすか）

注入は hook、遵守観測は別の定期実行。

## 実測 / 観測

手順が守られた率 0/24 を実測した前科がある。発火ログは「届いたか」の証拠であって「従ったか」の証拠ではない。

## 注記

注入経路がメインの対話にしか届かず、実装を担うサブエージェントには届かない点も同時に確認すること。
