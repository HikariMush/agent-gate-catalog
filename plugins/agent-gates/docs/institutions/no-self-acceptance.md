# 自己検収の禁止

**1行**: 実装した本人（同一セッション・同一の人格）が自分の成果物に合格を出せない。合格宣言の前に台帳照会コマンドを実行させ、監査者と発注者が同一なら非0で落とす。

## 世界標準の名前

Four-eyes principle / maker-checker / Segregation of Duties。エージェント文脈でも「1つのエージェントがワークフロー全段を握らない」設計として名前が付いている。

## 発火（何がこれを動かすか）

合格を出す前の検問（コマンドの終了コード）。

## 実測 / 観測

未発注・保留中・期限超過・中断・自己検収のいずれでも非0になることを実証済み。

## 注記

規範ではなくコマンドで担保する形にしてある（「system prompt は instruction であって control ではない」という指摘に沿う）。
