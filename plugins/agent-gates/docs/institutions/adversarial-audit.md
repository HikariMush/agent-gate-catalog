# 敵対監査の4層

**1行**: 層1 完了の定義 / 層2 検収の型（自己検収の禁止）/ 層3 新鮮な目の敵対監査（必須スイープ）/ 層4 裁定パッケージ。公理（何が本線か・前提そのもの）も検査対象に含める。

## 世界標準の名前

Red teaming / adversarial review ＋ Structured Analytic Techniques（Heuer/Pherson）。公理検査 = key assumptions check、反証探索 = analysis of competing hypotheses、対抗仮説 = devil's advocacy に対応する。

## 発火（何がこれを動かすか）

節目（go 判定後 / 公開・課金の前 / 月次判断 / 号令時）＋ 週次で監査タスクを撒く定期実行。

## 実測 / 観測

指摘には証拠（引用 or 実出力）を義務づけ、証拠のないものは所感欄に隔離する。件数のノルマは置かない。

## 注記

「批評の鋭さをモデルの地力に期待せず、発明を照合に置き直す」という設計思想は、structured analytic techniques の存在理由そのもの。
