## 分母の注記

世界標準の **override rate の分母は「人がレビューした提案の数」**。上の `0 / 11` の分母は「**レビューされずに期限で自動確定した件数**」で、rubber-stamp 側の量にあたる。この数字が言えるのは「拒否猶予が与えられた11件について、期限後に覆した記録が1件も無い」までで、「人がレビューした上で0件しか覆さなかった」ではない。

## 制約

- **履歴は1週分しかない**。集計器自身が「2週連続の判定が成立しない」と出力する。**時系列で改善したという主張はできない**
- 週次記録と再採取で値が動く。どの時点の数字かを添えないと比較できない
- 集計器がデータ異常を1件報告している（同一IDが未解決と解決済みの両方に存在）。主要な数字への影響は無く、参考値の 45.8%（11/24）が 47.8%（11/23）に動く範囲にとどまる
- 相互監査の面は10分ごとに再生成されるので、分母は採取のたびに動く

## 測っていないもの（「無い」と書く）

- **推奨採用率**（提示した推奨案がそのまま採られた率）: 採用案を記録する機械可読フィールドが存在しない
- **承認率**（行為単位の承認のうち人が承認した率）: 行為単位の承認を採らない設計なので、分母になる承認要求の件数が存在しない
- **介入率**（走行中に人が止めた回数）: 記録していない
- **導入の前後比較**: 履歴が1週分しかない
- **時間・コストの削減額**: 計測していない
